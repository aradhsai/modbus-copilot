Modbus copilot

Point at a device, load its tag database, check it is real, then hand it to an assistant.

1 — device
2 — tag database
Column names are matched loosely. 40001 becomes holding register 0, 30006 becomes input 5.
3 — check it is real

Reads every tag several times. Reports what answers, what never moves, and what does not exist — before anything downstream is built on the map.

4 — connect an assistant

Adds modbus-copilot to Claude Desktop's config. Your other MCP servers are kept, and the file is backed up first.

{ "mcpServers": { "modbus-copilot": { "url": "http://127.0.0.1:1880/mcp" } } }
Read-only by construction: the server exposes no write tool, so an assistant can reason about the plant but never change it.
